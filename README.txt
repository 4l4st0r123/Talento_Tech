 * Qué hace el proyecto.
Es un sitio web que busca presentar un comercio de productos hechos en impresoras 3d, permitira vender productos ya elaborados por el vendedor como tambien recibir peticiones en caso de que el cliente tenga un diseño pensado.

 * Por qué el proyecto es útil.
Permite una interaccion entre el cliente y el vendedor que permita detallar el objeto que se desea imprimir. Pudiendo pedir que haga un juguete u objeto en especifico que el cliente desea tener, o poder detallar una pieza de dimensiones especificas que reemplace una parte rota de un dispositivo.
